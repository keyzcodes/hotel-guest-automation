# Hotel Guest Ops

Cleanup-stage prototype foundation. Intended product: standalone guest messaging, scheduled stay touchpoints and tracked staff requests. The complete demo is not implemented yet.

Read docs/PRODUCT.md, docs/ARCHITECTURE.md and docs/CLEANUP.md before development.

- backend/: Express/MongoDB booking, ticket and Telegram code, with known gaps.
- frontend/: Next.js visual draft; buttons are not operational after legacy route cleanup.
- backend/tools/testBot.js: manual Telegram diagnostic, not an automated test.

No production-ready, live WhatsApp, smart-room, zero-cost hosting or test-pass claims are made. Original source snapshot remains separate. Credentials are not included.
